# 캣타워 다이스 게임 — 컨셉 초안

## 한 줄 소개

고양이 주사위들을 캣타워에 배치하고, 한 번에 굴려 연쇄 시너지와 배수를 만드는 세팅 중심 로그라이크 주사위 게임.

## 핵심 플레이 루프

1. **고양이 다이스 획득** — 상점 / 이벤트 / 보상
2. **캣타워 세팅** — 제한된 층에 고양이 배치 (어디에 넣는가가 핵심)
3. **굴림** — 턴 시작 시 전체 동시 굴림, 조작 없음, 연쇄·배수 자동 발동
4. **결과 정산** — 점수·골드·신규 다이스·층 강화

## 핵심 철학

플레이어는 **조작**이 아니라 **설계**를 한다.

- 중요: 확률 조작, 시너지 발견, 구조 최적화, 배수 설계
- 덜 중요: 피지컬, 반응속도, 실시간 컨트롤

## 캣타워

- 아래층 = 안정성 / 위층 = 고배수·고리스크

## 시너지

1. **세로** — 같은 면이 연속 층에 나오면 배수
2. **층** — 고양이별 선호 층에서 강화
3. **면** — 특정 조합 시 특수 상태 (식빵+잠듦 → 평온, 하악+긁기 → 난동)
