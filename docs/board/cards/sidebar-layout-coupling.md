# 사이드바·오버레이 레이아웃 결합 해제

> `ActiveHandsSidebar` 폭에 맞춘 하드코딩 offset/margin을 레이아웃으로만 해결되게 한다.

## 배경

`ui-editor-friendly`에서 확인한 잔여 이슈.

| 값 | 위치 | 역할 |
|---|---|---|
| `offset_right = -236` | `%ScoreOverlay` | 우측 사이드바(폭 252) 회피 |
| `margin_right = 268` | `MarginContainer` | 본문과 사이드바 간격 |

사이드바를 옮기거나 폭을 바꾸면 크래시는 없지만, `ScorePhasePresenter`의 주사위 확대 연출 위치가 조용히 어긋난다.

## 후보 방향

- 본문과 사이드바를 같은 `HBox`/`Split`에 두어 offset 회피 제거
- 연출 레이어를 본문 영역에만 두고 사이드바와 독립

## 완료 조건

- [ ] 사이드바 폭·위치를 바꿔도 점수 연출 앵커가 깨지지 않는다
- [ ] 하드코딩된 `-236` / `268` 회피 값이 제거(또는 한곳으로 문서화)됐다
