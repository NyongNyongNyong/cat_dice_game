# 주사위 설명 팝업 세로 리스트 개편

> 면을 세로 리스트로 나열하고 각 행 오른쪽에 설명을 적는 형태.

## 상세

- 현재: 가로 미니 주사위 나열 (+ 특수면 설명 영역).
- 목표: 세로 리스트 — 왼쪽 면 미리보기, 오른쪽 설명 텍스트.
- 관련: `face_preview_presenter`, `hover-special-face-desc`.

## 완료 조건

- [ ] hover 팝업이 세로 행 리스트다 (면 | 설명).
- [ ] 숫자면·특수면 모두 행으로 표시된다.
- [ ] 플레이·상점 hover에서 확인 가능하다.
