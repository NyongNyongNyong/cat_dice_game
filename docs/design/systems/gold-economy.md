## 목적

라운드 **칩**(점수)과 **골드**(오버킬 보상·소비 재화)를 분리해 Push Your Luck 의사결정을 만든다.

| 재화 | 역할 |
|------|------|
| **칩** | 라운드 점수 (`Σ(숫자) × Σ(족보)`). 목표 칩 달성 = 층 클리어 조건 |
| **골드** | 목표 초과(오버킬) 보상. 상점 구매·라운드 중 리롤 비용 |

플레이어는 목표 달성 후 **멈추고 골드를 확보할지**, **골드를 투자해 다음 보상 구간을 노릴지** 고민한다.

---

## 동작 조건

### 칩 (라운드 점수)

- `RunManager.current_score` = 이번 라운드 최종 칩 (족보 계산 결과).
- UI 표기: `칩: N`, `목표: T` (기존 "점수" 문구 대체).
- 클리어: `current_score >= target_score` (변경 없음).

### 골드 획득 시점

- **상점 진입 직전** (`Next Floor` → 상점 오픈)에 이번 라운드 골드를 **1회** 지급한다.
- 지급량 = [골드 획득 공식 v1](#골드-획득-공식-v1) (`S` = 최종 칩, `T` = 목표 칩).
- 런 시작 시 골드 `0`. 층을 넘어가도 누적 유지.

### 리롤 비용

| 상황 | 비용 |
|------|------|
| 목표 칩 **미달** (`current_score < target_score`) | **0** — 기존과 같이 무료 리롤 |
| 목표 칩 **달성** (`current_score >= target_score`) | **1골드** / 1회 (상수 `REROLL_GOLD_COST`, 추후 데이터화 가능) |

- 골드가 부족하면 목표 달성 후 **리롤 불가** (선택·Preview는 유지, Roll 버튼 비활성).
- 리롤 시도 시 골드를 **즉시 차감**한 뒤 주사위를 굴린다.

### 상점 (이번 범위)

- 상점 오퍼 **골드 가격은 미구현** (교체 무료 유지). 골드는 표시·누적만 한다.
- 추후 주사위·유물·매수에 골드 소비를 [dice-roster-shop.md](dice-roster-shop.md)에서 확장.

## 골드 획득 공식 v1

### 변수

| 기호 | 의미 |
|------|------|
| `T` | 목표 칩 |
| `S` | 최종 칩 (라운드 종료 시점) |
| `P` | 보상 구간 비율 (기본 **0.5**) |
| `k` | `floor((S - T) / (T × P))` — 목표 달성 후 완료한 **추가 구간** 수 (`S = T`이면 `k = 0`) |

### 규칙

```
S < T  →  획득 골드 = 0

S ≥ T  →  획득 골드 = (k + 1) × (k + 2) / 2
```

등가 표기: `n = k + 1`(달성한 보상 **단계** 수, 최소 1)일 때 `획득 골드 = n × (n + 1) / 2`.

> **메모:** `1 + k(k+1)/2` 형태는 예시 수치와 불일치한다. **예시·표가 정본**이며 구현은 `(k+1)(k+2)/2`를 따른다.

### 추천 설정 예 (`T = 100`, `P = 0.5`)

| 최종 칩 `S` | `k` | 획득 골드 | 누적 의미 |
|-------------|-----|-----------|-----------|
| 99 | — | 0 | 미달 |
| 100 | 0 | 1 | 기본 1골드 |
| 149 | 0 | 1 | 첫 구간 내 |
| 150 | 1 | 3 | +2 (총 3) |
| 199 | 1 | 3 | |
| 200 | 2 | 6 | +3 (총 6) |
| 250 | 3 | 10 | |
| 300 | 4 | 15 | |
| 350 | 5 | 21 | |

구간 경계: `T`, `T + T×P`, `T + 2×T×P`, … (= 100, 150, 200, …).

## 계산 방식

- `GoldCalculator.calculate_reward(final_chips, target_chips, interval_ratio)` — 정수 골드 반환.
- `T <= 0`이면 0 반환 (안전 가드).
- 족보·칩 합산 로직은 변경하지 않는다.

## 예외 조건

| 상황 | 동작 |
|------|------|
| `S < T` | 골드 0, 리롤 무료 |
| `T <= 0` | 골드 0 |
| 목표 달성 후 골드 0 | 리롤 불가, Next Floor 가능 |
| 상점 중 | 리롤·굴림 비활성 (기존) |
| 5층 클리어 | 마지막 층 상점 진입 시에도 골드 지급 |
