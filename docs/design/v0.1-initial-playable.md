# 캣타워 카지노 설계 v0.1 — 초기 플레이어블

> **문서 유형:** 구현 설계  
> **기획 참조:** [gdd-cat-tower-casino.md](../gdd-cat-tower-casino.md)  
> **상태:** v0.1 초안

---

## 1. 목적

이 버전은 풀 게임이 아니라, **핵심 루프가 재미있는지 검증**하기 위한 최소 플레이어블이다.

검증 질문:

> 주사위를 굴리고 점수를 얻고 다음 층으로 올라가는 행위 자체가 재미의 씨앗이 될 수 있는가?

기획 문서에 정의된 특수 주사위·카지노 규칙·유물·상점 등은 **이 버전 범위 밖**이다.  
재미가 확인되면 이후 설계 버전에서 시스템을 단계적으로 추가한다.

## 3. 구현 범위

### 3.1 플레이 흐름

```text
게임 시작
    ↓
1층 진입
    ↓
주사위 10개 굴림
    ↓
점수 계산
    ↓
목표 점수 달성 여부 확인
    ↓
다음 층
    ↓
5층 도달
    ↓
v0.1 완료
```

### 3.2 이 버전에서 구현하지 않음

| 제외 | 비고 |
|------|------|
| 리롤 | 추후 설계 |
| 주사위 잠금 | 추후 설계 |
| 특수 주사위 | GDD §4 — v0.1 이후 |
| 카지노 규칙 | GDD §5 — v0.1 이후 |
| 유물 | GDD §7 |
| 상점 | GDD §6 |
| 소비 아이템 | GDD §7 |
| 보스 | GDD §11 미정 |
| 메타 성장 | GDD §11 미정 |
| 세이브 / 로드 | 추후 |
| 업적 | 추후 |
| 온라인 | 추후 |

`game/data/`의 풀 게임 JSON(카지노 규칙, 족보, 상점 풀 등)은 **이 버전에서 로드하지 않는다.**

## 4. 씬 구조

### 4.1 Main

프로젝트 시작 씬 (`run/main_scene`).

```text

├── UI
└── RunScene
```

| 파일 (예정) | 경로 |

실제 게임 플레이.

```text
RunScene
├── FloorLabel
├── TargetScoreLabel

```

| 파일 (예정) | 경로 |
|-------------|------|
| `run_scene.tscn` | `res://scenes/game/run_scene.tscn` |

역할: 현재 눈 표시, 굴림 결과 업데이트.

| 파일 (예정) | 경로 |
|-------------|------|
| `dice.tscn` | `res://scenes/dice/dice.tscn` |
| `dice.gd` | `res://scripts/dice/dice.gd` |

## 5. 게임 규칙

### 5.1 층 구조

총 5층. 목표 점수는 임시 수치.

| 층 | 목표 점수 |
|----|-----------|
| 1 | 50 |
| 2 | 70 |
| 3 | 90 |
| 4 | 120 |
| 5 | 150 |

### 5.2 라운드 흐름

1. 층 진입 — `RunManager`가 `targetScore` 설정
2. **Roll** 클릭 — 주사위 10개 `1~6` 굴림
3. `ScoreCalculator`로 점수 계산
4. `currentScore >= targetScore`이면 **Next Floor** 활성화
5. 다음 층 이동 — 5층 클리어 시 v0.1 종료

---

## 6. 주사위

- 기본 주사위만 사용
- 면: `1, 2, 3, 4, 5, 6`
- 한 라운드당 **10개**

---

## 7. 점수

v0.1은 족보 없음.

```text
점수 = 모든 주사위 숫자의 합
```

예: `1, 4, 6, 2, 5, 3, 4, 2, 6, 1` → **34점**

> GDD §9의 `Σ(숫자) × Σ(족보 가치)`는 [hand-scoring-v1.md](../systems/hand-scoring-v1.md) 스펙으로 정의됨. v0.1 구현은 숫자 합만.

## 9. 스크립트

### 9.1 RunManager (Autoload)

| 역할 | 층 진행, 목표 점수 관리, 클리어 판정 |
|------|--------------------------------------|
| 경로 | `res://scripts/autoload/run_manager.gd` |
| 보유 | `current_floor`, `target_score`, `current_score` |

층별 목표 점수 테이블을 보유하고, 층 이동·클리어 여부를 판정한다.

### 9.2 ScoreCalculator

| 역할 | 점수 계산 전담 |
|------|----------------|
| 경로 | `res://scripts/core/score_calculator.gd` |
| 함수 | `calculate_score(dice_values: Array[int]) -> int` |

v0.1: 입력 주사위 목록의 **숫자 총합**만 반환.
