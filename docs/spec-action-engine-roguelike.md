# 액션 주사위 엔진 — 게임 스펙

> 정해진 액션 횟수를 드로우·굴리기·리롤·잠금에 분배하며, 매 턴 점수를 벌고 유물·시너지로 주사위 엔진을 키우는 전략 로그라이크.

**문서 상태:** 컨셉 스펙 v0.6.1  
**관련 문서:** [캣타워 다이스 컨셉 (이전 방향)](cat-tower-concept.md)

---

## 1. 한 줄 정의

**제한된 액션 안에서 최대한 아름다운 주사위 엔진을 만드는 게임.**

단순 족보·숫자 합 게임이 아니라, **상태 조합 기반 엔진빌딩** 로그라이크.

---

## 2. 핵심 재미

| 축 | 설명 |
|----|------|
| **액션 최적화** | 턴당 N개 액션을 드로우/굴림/리롤/잠금에 자유 분배 |
| **엔진 빌드 다양성** | 물량·리롤·잠금·증폭·복사·연쇄 등 **여러 빌드 축** 중 선택·조합 |
| **상태 조작** | 주사위별 상태(태그·배수·잠금) 설계 |
| **유물 시너지** | 규칙을 깨는 유물로 엔진 강화 |
| **연쇄 폭발** | 트리거 체인으로 한 턴 점수 급등 (리롤만이 아님) |
| **빌드 성장** | 초반 약함 → 유물·시너지로 후반 점수 폭발 |

---

## 3. 메타 구조 (런 · 스테이지 · 턴)

### 3.1 계층

```
런 (15~30분)
 └─ 스테이지 (3~7턴 권장)
     └─ 턴 (액션 N개 사용 → 점수 정산)
```

### 3.2 스테이지 흐름

1. **스테이지 시작** — 목표 점수 · (D) 스테이지 규칙 · **시작 핸드** 배치 (§5.2)
2. 여러 **턴** 진행 — **스테이지 동안** **핸드·굴림** 모두 유지 (턴 종료해도 각 구역 그대로)
3. 매 턴: 액션 사용 → **턴 점수** 정산 (**굴림** 주사위 기준)
4. 턴 점수를 **스테이지 누적 점수**에 합산
5. 누적 ≥ 목표 → **스테이지 클리어** → 보상·아이템 → **핸드·굴림 초기화** → 다음 스테이지
6. 누적 < 목표로 턴 소진 → 실패 처리 (별도 규칙 정의 필요)

**핵심:** 턴마다 주사위를 **0부터 다시 깔지 않음**. 스테이지 = **핸드 + 굴림**을 여러 턴에 걸쳐 키우는 구조.

### 3.3 누적 점수 예시

| 항목 | 값 |
|------|-----|
| 스테이지 목표 | 100점 |
| 턴1 | +12 → 누적 12 |
| 턴2 | +18 → 누적 30 |
| 턴3 | +27 → 누적 57 |
| 턴4 | +48 → 누적 **105** → 클리어 |

**설계 의도:** 초반은 낮은 점수, 유물·시너지 누적으로 후반 턴에서 급성장.

## 4. 턴 구조

### 4.1 턴 시작

- 플레이어에게 **액션 5개** 부여
- **핸드·굴림**은 스테이지 시작·이전 턴에서 **이어짐** (§5.2)
- (아이템·패시브에 따라 변동 가능)

### 4.2 턴 중

액션을 **순서·종류·횟수** 자유 분배.

**예 A:** 드로우 2 · 굴림 1 · 잠금 1  
**예 B:** 드로우 2 · 굴림 2 *(물량 — 많이 뽑고 많이 굴림)*  
**예 C:** 드로우 1 · 리롤 2 · 잠금 1  

※ 리롤에만 액션을 몰아쓰는 것은 **가능한 플레이 중 하나**일 뿐, 필수 패턴이 아님.

액션 소진 또는 **턴 종료** 선택 시 턴 종료.

### 4.3 턴 종료

1. **굴림** 주사위만 대상으로 점수 정산 (§5.4)
2. **핸드·굴림 유지** — 주사위 **제거·이동 없음** (각 구역·상태 그대로)
3. 다음 턴: 같은 핸드·굴림 + **액션 5개** 새로 부여

**스테이지 종료 시에만** **핸드·굴림 전부 초기화** → 다음 스테이지 **시작 핸드**로 (§5.2).  
*(v0.2+ 아이템: **굴림**의 잠긴 주사위를 스테이지 넘어 이월 등 — §8)*

## 5. 기본 액션

| 액션 | 비용 | 효과 |
|------|------|------|
| **드로우** | 1 | 주머니에서 주사위 1개를 **핸드**에 추가 |
| **굴리기** | 1 | **핸드**에서 미굴림 주사위 **1개** 선택 → **굴림**으로 이동·눈 확정 |
| **리롤** | 1 | **굴림**의 **미잠금** 주사위 **1개** 다시 굴림 |
| **잠금** | 1 | **굴림**의 **굴린** 주사위 **1개** 잠금 (§5.1) |
| **턴 종료** | 0 | 즉시 점수 정산 · 턴 종료 (§5.2) |

### 5.1 잠금 (Lock)

**v0 규칙**

- **굴린 뒤**에만 잠금 가능
- **잠금 해제 불가**
- 잠긴 주사위: 플레이어 **리롤 불가** (추후 **강제 리롤** 면역은 유물·효과 레이어)

**v0.1 — 잠금 보상 (C)**  
- 잠긴 주사위 1개당, 그 주사위 **눈값을 점수에 2번 더함** (해당 주사위 ×2)

**역할:** 「리롤 안 하겠다」를 넘어, **확정 + 점수 보상**으로 잠금·리롤 트레이드오프를 만든다.

### 5.2 v0 턴 · 핸드 · 굴림 · 주머니 (확정)

#### 주사위 구역 (용어)

| 구역 | 내용 | 드로우·굴리기 |
|------|------|----------------|
| **주머니** | d6 무한 공급원 | 드로우 출처 |
| **핸드** | **미굴림** 주사위만 | 드로우 목적지 · 굴리기 출처 |
| **굴림** | **눈이 확정된** 주사위 (잠금 포함) | 굴리기 목적지 · 리롤·잠금 대상 |

> **핸드 ≠ 굴림.** 핸드는 「아직 안 굴린 주사위」, 굴림은 「이미 굴린 주사위(잠긴 것 포함)」.  
> **잠금**은 굴림 **안의 상태**이지, 핸드에 있는 것이 아님.

| 항목 | 규칙 |
|------|------|
| 턴당 액션 | **5회** |
| 액션 이월 | **불가** |
| 턴 종료 | **언제든** 가능 (액션 남아도 OK) |
| **시작 핸드** | **스테이지 시작** 시 d6 **2개** → **핸드**에 (미굴림) — v0.1 |
| **스테이지 내 유지** | 턴 종료해도 **핸드·굴림 각각** 그대로 (별개 구역, **동시에** 유지) |
| **스테이지 종료** | **핸드·굴림 전부** 초기화 → 다음 스테이지 시작 핸드 |
| 주사위 **총 상한** | **5개** (핸드 + 굴림 합산) — 초과 시 **드로우 불가** |
| 주머니 (프로토) | **표준 d6** (무한) |
| 한 액션 대상 | 드로우/굴림/리롤/잠금 각 **1개** |

**설계 의도**

- **턴 1:** 시작 핸드 2개 → 드로우로 핸드 키움 → 굴리기로 **굴림**에 쌓음  
- **턴 2~:** **굴림**의 잠긴 6 · **핸드**의 미굴림 1개 등 **구역별로** 이어서 전략  
- **족보·잠금**은 **굴림**을 여러 턴에 걸쳐 키우는 축 (아이템 있을 때)

**흐름** (스테이지 내내 각 구역·상태 유지)

```
주머니 ──드로우──► [핸드·미굴림] ──굴리기──► [굴림] ──잠금──► [굴림·잠금]
                                           ↘ 리롤 (미잠금만)
         턴 종료 → 핸드·굴림 모두 그대로 → 다음 턴
         스테이지 종료 → 핸드·굴림 초기화 (아이템 예외 §8)
```

### 5.3 v0.1 점수 레이어 (A · B · C · D)

v0.1은 **A·C·D**를 항상 쓰고, **(B) 족보**는 **아이템**을 가져야만 점수원이 된다.  
물량·연쇄·강제 리롤 등은 **v0.2+** · 아이템 확장.

> **아이템** = 런 동안 보유하는 규칙 수정품 (§8, 구 「유물/조커」. 명칭 변경 예정)

#### (A) 턴 목표 1장

매 **턴 시작** 시 목표 1장 공개. **턴 종료 정산 시** 조건 충족하면 **보너스 점수** (한 번).

| 목표 예시 | 보너스 |
|-----------|--------|
| 굴린 주사위 **3개 이상** | +6 |
| **6**이 1개 이상 | +4 |
| 굴린 눈 중 **짝수** 2개 이상 | +5 |
| 굴린 주사위 **합 18 이상** | +8 |
| *(페어 아이템 보유 시)* **페어** 1개 이상 | +4 |

- 턴마다 풀에서 1장 랜덤 (중복 가능)
- **족보 목표**는 해당 **족보 아이템 보유 시에만** 풀 등장
- UI: 턴 목표 카드 상시 표시

#### (B) 족보 — **아이템에 따라** 점수화

**기본:** 아이템 없으면 **족보 0점** (합계 + A + C + D만).

**아이템 보유 시:** 해당 **족보 타입**이 턴 종료 정산에 **추가 점수원**으로 활성화.  
**굴린 주사위**만 대상. **합계와 별도 가산**. 한 턴 **여러 족보 동시 달성 시 중복 허용**.

| 족보 | 조건 (굴린 주사위) | 점수 (v0.1) | 활성화 아이템 |
|------|-------------------|-------------|----------------|
| **페어** | 같은 숫자 2개 | +6 | **짝 맞추기 판** |
| **트리플** | 같은 숫자 3개 | +12 | **세 줄표** |
| **스트레이트** | 연속 숫자 3개+ (예 2-3-4) | +10 | **계단 조각** |
| **두 페어** | 페어 2조 | +14 | **쌍둥이 카탈로그** |
| **풀하ouse** | 트리플 + 페어 | +22 | **완성 도감** |
| **포카드** | 같은 숫자 4개 | +20 | **네 고양이** |
| **올 동일** | 같은 숫자 5개 | +35 | **다섯 발바닥** |

- **아이템 1개 = 족보 1종 활성화**
- v0.2+: 같은 족보 **강화** 아이템 (페어 +6 → +10 등)
- UI: 보유 아이템 = **활성 족보** 표시 · 정산 시 달성 족보 하이라이트

**설계 의도:** 족보는 **빌드 선택**. 페어 / 트리플 / 스트레이트 / **합계·물량** 루트가 아이템에 따라 갈린다.

#### (C) 잠금 배수

§5.1 — 잠긴 주사위 **눈값 ×2** (합산 시 해당 칸만 2배).

#### (D) 스테이지 규칙 1개

**스테이지 시작** 시 규칙 1개 적용. **스테이지 내내** 유지.

| 규칙 예시 | 효과 |
|-----------|------|
| **짝수만** | 홀수 눈 주사위는 **점수 합산에서 0** |
| **5 이상만** | 4 이하 눈은 **합산 0** |
| **홀수 보너스** | 홀수 눈 1개당 **+2** (합계와 별도) |
| **저합 스테이지** | 턴 **합계 15 이하**일 때 **+6** |

- 스테이지마다 풀에서 1개 (v0.1: 2~3종만 구현해도 됨)
- UI: 스테이지 상단에 규칙 1줄 고정 표시

### 5.4 v0.1 턴 점수 정산 순서

```
1. **굴림** 주사위 전부 (핸드의 미굴림은 0점 · **핸드에 유지**)
2. 각 주사위 눈값 **합계** — 잠긴 주사위는 ×2 (C)
3. (D) 스테이지 규칙 적용
4. (B) **보유 아이템으로 활성화된 족보**만 판정 · 가산
5. (A) 턴 목표 달성 시 보너스 가산
→ = 이번 턴 점수 → 스테이지 누적
   (핸드·굴림 상태는 정산 후 **그대로**)
```

> **주의:** 이전 턴에 **굴림**에 둔·잠근 주사위도 **매 턴 정산에 포함**된다. 족보·잠금은 **굴림**을 스테이지 내내 키우는 축.

**예 (D=짝수만, C=6 잠금, **짝 맞추기 판** 보유, A=합18+):**  
굴림 4,4,6(잠금),3 → 합계: 4+4+12=20 → 짝수만: 4+4+12=20 → 페어 +6 → 합18+ +8 → **34점**

**예 (족보 아이템 없음):**  
굴림 6,6,6,2 → 합계 20 → 족보 0 → **20점** (트리ple이 있어도 아이템 없으면 무시)

## 6. 점수·엔진 시스템

### 6.1 방향성

**기본 점수**는 굴린 주사위 **합계** (+ 잠금·스테이지·턴 목표).  
**족보**는 **아이템으로 잠금 해제**되는 점수원 — 항상 켜져 있는 족보 게임이 아니다.

**리롤·물량·잠금·족보** 등은 **동등한 빌드 축** 후보. 아이템이 어떤 축을 열어주느냐가 런의 정체성.

### 6.2 빌드 축 (동등 · 조합 가능)

| 축 | 핵심 질문 | 예시 효과 |
|----|-----------|-----------|
| **물량 (다뽑·다굴림)** | 액션을 **드로우+굴림**에 써서 주사위를 많이 돌릴 것인가 | 합계 보너스, 굴린 개수×점수, 드로우·굴림 할인, 연쇄 트리거 빈도↑ |
| **족보** | 어떤 **패**를 노릴 것인가 | 페어·트리플·스트레이트 *(아이템 활성화)* |
| **잠금·유지** | **굴림**의 좋은 상태를 스테이지 내내 지킬 것인가 | 잠금, 굴림 유지, 복사 |
| **증폭·배수** | 한 주사위·한 숫자를 키울 것인가 | ×2 태그, 이웃 증폭, 스택 배수 |
| **복사** | 효과를 어떻게 퍼뜨릴 것인가 | 인접 복사, 유지 주사위 복제 |
| **리롤** | 확률을 몇 번 더 쓸 것인가 | 리롤당 점수, 무료 리롤, 확률 왜곡 |
| **연쇄·트리거** | 무엇이 다음 효과를 부를 것인가 | 6→연쇄, 면 매칭, 턴 종료 폭주 |
| **강제 변화** | 구성을 억지로 흔들 것인가 | 강제 리롤, 면 교체, 셔플 |

플레이어는 턴당 액션 한정 안에서 **위 축 중 1~2개를 중심**으로 엔진을 짓거나, 유물로 여러 축을 엮는다.

### 6.3 물량 (다뽑·다굴림)

**많이 뽑고, 많이 굴리는** 쪽도 재미 축으로 본다.

| 예시 | 설명 |
|------|------|
| 굴린 주사위 **합계**가 점수의 기본 | 숫자가 많을수록 기대값 상승 |
| **N개 이상** 굴렸을 때 보너스 | 유물·패시브와 결합 |
| 드로우·굴림 **액션 할인** | 물량 빌드 성장 |
| 주사위마다 **작은 트리거** | 많이 굴릴수록 연쇄 기회 증가 |

리롤·잠금과 **대립**이 아니라, 「액션을 굴림에 쓸지 리롤에 쓸지」의 **분배 선택**이다.

### 6.4 리롤 (빌드 축 중 하나)

리롤 관련 효과·유물은 **존재하되**, 게임의 유일한 정답이 아니다.

| 예시 (리롤 축) | 설명 |
|----------------|------|
| 리롤 횟수 비례 점수 | 턴 내 리롤 N회 → +N×k |
| 무료·할인 리롤 | 액션 효율 |
| 리롤 시 배수·확률 변화 | 왜곡된 면, 광란 엔진 등 |

### 6.5 강제 리롤 (리스크·연쇄용 서브 시스템)

**다른 주사위**를 플레이어 의사와 무관하게 다시 굴림.

**예 — [폭주]:** 턴 종료 시 다른 주사위 2개 자동 리롤

**역할:** 리스크·변동성, 연쇄 촉매, **잠금** 가치 상승 — 주로 **연쇄·잠금 빌드**와 맞물림.

### 6.6 자동 연쇄 (연출 목표)

연쇄는 리롤에만 묶이지 않는다.

```
예 A) 6 등장 → 인접 증폭 → 점수 폭발
예 B) 잠금 3개 → 턴 종료 보너스
예 C) 리롤 → 트리거 → 자동 효과 → 연쇄
```

**스펙 요구:** 연쇄 단계가 **한눈에 읽히는** 연출·로그 (§10).

## 7. 전략 아키타입

| 유형 | 목표 | 예시 플레이 |
|------|------|-------------|
| **안전 운영** | 이번 턴 점수 확보 | 드로우·굴림 위주, 잠금으로 핵심 유지 |
| **성장 운영** | 스테이지 후반 포텐 | 족보·리롤 등 **아이템** 조합에 액션 투자 |

### 7.1 빌드 예시 (동등 · 대표만)

1. **물량 빌드** — 드로우·굴림 위주, 많이 뽑고 많이 던져 합계·개수 시너지
2. **고숫자·합계 빌드** — 합 18+ · 스테이지 규칙 활용 (족보 아이템 없이)
3. **족보 빌드** — 페어/트리플/스트레이트 **아이템** 중심 · 리롤·잠금으로 패 완성
4. **잠금·유지 빌드** — **굴림**에 좋은 주사위 고정 · 턴 넘겨 족보 완성
5. **증폭 빌드** — 한 주사위를 키워 배수 폭발
6. **복사 빌드** — 강한 효과 확산
7. **리롤 빌드** — 리롤 횟수·확률 왜곡 중심 *(다른 빌드와 동급)*
8. **연쇄·트리거 빌드** — 면/숫자 조건으로 자동 발동
9. **혼합** — 아이템 2~3개로 축 교차 (실전에서 가장 흔함)

## 8. 아이템 (구 유물 / 조커)

> 명칭 **아이템**으로 통일 예정. 클로버핏류 명칭과 겹치지 않게 별도 네이밍.

### 8.1 역할

**게임 규칙을 일부 깨거나 점수원을 여는** 런 내 영구 보정.

- **족보 활성화** (§5.3 B) — 핵심 카테고리
- 스테이지 경계 **추가 유지** · 액션 할인 · 연쇄 등 (v0.2+)

| **짝 맞추기 판** | 페어 | +6 |
| **세 줄표** | 트리플 | +12 |
| **계단 조각** | 스트레이트 (3+) | +10 |

- 스테이지 클리어 / 상점 보상으로 획득
