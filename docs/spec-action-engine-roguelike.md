> Yahtzee류 "잠그고 전체 리롤" 구조 + 로그라이크 아이템/시너지/빌드 분기.

**문서 상태:** 컨셉 스펙 v0.9

## 1. 한 줄 정의

**제한된 리롤 안에서 주사위를 잠그며 엔진을 조립하는 전략 로그라이크.**

---

## 2. 핵심 플레이 감각

핵심은:

- 무엇을 **잠글지**
- 언제 **전체 리롤**할지
- 언제 만족하고 **턴을 끝낼지**
- **추가 주사위**를 더 가져갈지

를 판단하는 **운영 퍼즐**.

자동 전투 관전이 아니라, **"현재 판을 어떻게 관리할 것인가"** 가 중심.

---

## 3. 메타 구조 (런 · 스테이지 · 턴)

### 3.1 계층

```
런 (15~30분)
 └─ 스테이지 (3~7턴)
     └─ 턴 (리롤·잠금·추가 → 점수 정산 → 필드 리셋)
```

### 3.2 스테이지 흐름

1. **스테이지 시작** — 목표 점수 · (D) 스테이지 규칙
2. 여러 **턴** 진행
3. 매 턴: 기본 5개 굴림 → 리롤/잠금/추가 → **점수 정산** → **필드 리셋**
4. 턴 점수를 **스테이지 누적 점수**에 합산
5. 누적 ≥ 목표 → **스테이지 클리어** → 아이템 보상 → 다음 스테이지
6. 누적 < 목표 & 턴 소진 → 실패

### 3.3 누적 점수 예시

| 항목 | 값 |
|------|-----|
| 스테이지 목표 | **50점** |
| 턴1 | +18 → 누적 18 |
| 턴2 | +14 → 누적 32 |
| 턴3 | +22 → 누적 **54** → 클리어 |

## 4. 턴 구조

### 4.1 턴 시작

- **기본 주사위 5개**를 **즉시 굴린 상태**로 배치
- **리롤 3회** 부여
- **추가 주사위 액션 2회** 부여

### 4.2 턴 중 — 핵심 루프

**리롤 ↔ 잠금** 이 핵심 루프.

#### (1) 전체 리롤

**잠기지 않은 모든** 주사위를 한꺼번에 다시 굴린다.  
잠긴 주사위는 유지. 리롤 1회 소모.

```
[2🔒] [2🔒] [4] [5] [6]  ← 현재
[2🔒] [2🔒] [1] [3] [6]  ← 전체 리롤 후 (4,5 바뀜 · 🔒 유지)
```

핵심 선택: 지금 만족하고 잠글 것인가? 더 높은 점수를 위해 리롤할 것인가?

#### (2) 잠금 (자유 · 비용 없음)

원하는 주사위를 **클릭하여 잠금 토글**. 비용 없음.

- 잠긴 주사위: 이후 리롤에서 **유지**
- 점수 정산 시 **×2** 배수
- 턴 종료 시 잠금 **소멸** (필드 리셋)

#### (3) 추가 주사위 (액션 1 소모)

주머니에서 **새 주사위 1개**를 추가로 굴려 필드에 배치.  
필드 상한 **8개**까지.

역할: 물량 빌드 · 족보 확장 · 고점 노리기 · 연쇄 트리거 증가

#### (4) 턴 종료

즉시 점수 정산 후 종료.  
필드 **전부 리셋**. 다음 턴: 새 기본 5개.

### 4.3 턴 종료 정산

```
1. 필드 전체 합계 (잠긴 주사위 ×2)
2. (D) 스테이지 규칙 적용
3. (B) 보유 아이템 족보 판정 · 가산
4. (A) 턴 목표 달성 시 보너스
→ 이번 턴 점수 → 스테이지 누적
→ 필드 리셋
```

## 5. 주사위 타입

**모든 주사위가 동일한 d6가 아니다.**  
다양한 성격의 주사위를 **엔진에 넣고 운영**하는 것이 핵심 전략.

| 타입 | 면 구성 | 특징 |
|------|---------|------|
| **안정형** | 2 2 3 3 4 4 | 평균 높음 · 족보 안정 · 리롤 효율 ↑ |
| **폭주형** | 1 1 1 6 6 6 | 고점 매우 높음 · 리스크 큼 · 잠금 가치 ↑ |
| **스트레이트형** | 1 2 3 4 5 6 | 스트레이트 특화 · 안정성 낮음 |
| **족보형** | 2 2 3 3 5 5 | 페어/트리플 잘 뜸 |
| **잠금형** | 3 3 4 4 5 5 | 안정 고점 · 잠금 시너지 강함 |

v0.9 데모: **안정형** 기본 5개 시작. 추가 주사위는 풀에서 **랜덤 타입**.

## 6. 점수 시스템

### 6.1 기본 점수

필드 주사위 눈값 합산. 잠긴 주사위는 **×2**.

```
[2🔒] [2🔒] [5] [6]
→ 4 + 4 + 5 + 6 = 19점
```

### 6.2 족보 (아이템 활성화)

아이템 없으면 **족보 0점**.

| 족보 | 조건 | 점수 | 활성화 아이템 |
|------|------|------|--------------|
| **페어** | 같은 숫자 2개 | +6 | 짝 맞추기 판 |
| **트리플** | 같은 숫자 3개 | +12 | 세 줄표 |
| **스트레이트** | 연속 3개+ | +10 | 계단 조각 |

### 6.3 턴 목표

매 턴 랜덤 목표 1개. 달성 시 보너스.

| 목표 | 보너스 |
|------|--------|
| 합 18 이상 | +8 |
| 6 포함 | +4 |
| 짝수 3개 이상 | +5 |
| 필드 6개 이상 | +6 |
| 페어 달성 (아이템 필요) | +4 |

### 6.4 스테이지 규칙

스테이지마다 1개. 스테이지 내내 유지.

| 규칙 | 효과 |
|------|------|
| 짝수만 | 홀수 눈 = 점수 0 |
| 5 이상만 | 4 이하 눈 = 점수 0 |
| 홀수 보너스 | 홀수 눈 1개당 +2 |
| 저합 보너스 | 합계 15 이하 시 +8 |

## 7. 아이템

**규칙을 깨는 것.** 런 시작 시 족보 아이템 **1개 랜덤**.  
스테이지 클리어 보상으로 추가.

### 7.1 족보 아이템 (v0.9 구현)

| 아이템 | 효과 |
|--------|------|
| **짝 맞추기 판** | 페어 +6 |
| **세 줄표** | 트리플 +12 |
| **계단 조각** | 스트레이트 +10 |

### 7.2 기타 아이템 (v0.9 구현)

| 아이템 | 효과 |
|--------|------|
| **과열 베어링** | 리롤할 때마다 +1점 |
| **낡은 접착제** | 턴 종료 후 잠긴 주사위 1개 다음 턴 유지 |

## 8. 밸런스

| 항목 | 값 |
|------|-----|
| 기본 주사위 | **5개** (턴 시작 자동 굴림) |
| 리롤 | **3회** / 턴 |
| 추가 주사위 | **2회** / 턴 (액션 소모) |
| 잠금 | **자유** (비용 없음 · 클릭 토글) |
| 필드 상한 | **8개** |
| 잠금 배수 | **×2** |
| 스테이지 목표 | 1스테이지 **50**, 이후 +20 |
| 턴/스테이지 | **5턴** |

## 9. UX 목표

**한눈에 읽혀야 한다.**

```
[6🔒×2] [2] [5]
```

유저가 즉시 이해 가능:
- 무엇이 잠겼는지
- 무엇이 위험한지
- 무엇이 고점인지
