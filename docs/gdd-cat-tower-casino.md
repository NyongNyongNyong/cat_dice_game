**문서 상태:** v0.2 방향 (2026-06-21 핵심 시스템 확정) · v0.1 코드는 과도기

## 1. 한 줄 소개

고양이들이 운영하는 거대한 **캣타워 카지노**를 층마다 올라가며, 다양한 **특수 주사위**를 수집하고 조합해 **최상층 금고**를 노리는 주사위 로그라이크.

---

## 2. 현재 방향성

Cat Tower Casino는 주사위를 **수집·배치·성장**시키며 탑을 오르는 로그라이크다.

런 동안 새 주사위를 획득하고, 기존 주사위를 **강화하거나 교체**하며 자신만의 빌드를 완성한다.

직접적인 **리롤** 대신 **행운(Luck)** 으로 운을 간접 제어한다.

| 축 | 설명 |
|----|------|
| 주사위 수집·교체 | 상점 구매, 기존 주사위 유지 vs 갈아타기 |
| 주사위 성장 | 강화 키트로 면 개조 — 같은 종류도 다른 빌드 |
| 3×4 보드 배치 | 배치 후 굴림 — 위치가 전략 |
| 빈칸 전략 | 12칸 중 8개만 채움 — 어디를 비울지 고민 |
| 행운 | 결과 분포 조정 — 리롤 없이 운 제어 |

**발라트로**처럼 엔진을 구축하는 재미는 유지하되, **배치·성장·행운**이 의사결정의 중심이다.

### 2.1 핵심 목표 (한 문장)

> 좋은 **숫자**를 만드는 게임이 아니라, 좋은 **주사위 엔진**을 만드는 게임.

플레이어가 새 주사위를 얻고, 보드에 배치하고, 면을 개조하며, 행운과 빈칸을 활용해 층을 올라가는 경험을 만든다.

### 2.2 v0.1 구현과의 차이 (과도기)

현재 플레이 가능 빌드(`v0.1-initial-playable.md`)는 아래와 다르다. **신규 기능은 §4 방향을 따른다.**

| 항목 | v0.1 (코드) | v0.2 (기획) |
|------|-------------|-------------|
| 보드 | 10슬롯 1열 | 3×4, 시작 4칸·4주사위 |
| 굴림 | 배치 없이 일괄 굴림 | **배치 → 굴림 → 효과 → 족보 → 점수** |

| 성장 | 미구현 | 강화 키트 (±1, 진화) |

## 4. 핵심 시스템 (2026-06-21)

### 4.1 보드

| 항목 | 값 |
|------|-----|
| 크기 | **3 × 4** (총 12칸) |
| 시작 주사위 | **4개** |
| 시작 해금 슬롯 | **4칸** |
| 최대 해금 슬롯 | **12칸** (상점 등으로 추가) |
| 최대 보유·배치 주사위 | **8개** |

**설계 의도:** 모든 칸을 채우는 것이 정답이 되지 않도록 한다. 어떤 칸을 쓰고 **어떤 칸을 비울지** 고민한다.

**빈칸 활용 (추후):** 빈칸과 상호작용하는 주사위·효과 — 예: 주변 빈칸당 점수 증가, 인접 없을 때 강화, 빈칸 수 비례 보너스.

**미정:** 슬롯 해금 비용·밸런스, 위치 효과 구체 설계.

---

### 4.2 배치 및 굴림

플레이어는 주사위를 **먼저 배치**한 뒤 굴린다.

```
주사위 배치
    ↓
주사위 굴림
    ↓
주사위 효과 처리
    ↓
족보 계산
    ↓
점수 계산
```

**설계 의도:** 위치 자체를 전략 요소로 만든다. 결과를 본 뒤 최적 배치를 찾는 것이 아니라, **현재 보유 주사위와 위치 효과**를 고려해 미리 배치 전략을 세운다.

---

### 4.3 운 제어 — 행운 (Luck)

**목표:** 리롤 없이도 운을 조절할 수 있는 시스템. 플레이어는 결과를 다시 굴리지 않고 **행운 스탯**으로 결과 분포를 조정한다.

**결과 생성 (개념):**

1. 일부 주사위를 랜덤 확정
2. 나머지 주사위의 모든 경우의 수 계산
3. 가능한 최종 점수 분포 생성
4. 행운 수치에 따라 분포 **일부 제거**
5. 남은 결과 중 하나를 랜덤 선택

**행운 효과:**

- 행운 **↑** → 낮은 점수 결과 제거
- 행운 **↓** (음수 포함) → 높은 점수 결과 제거
- 행운은 **최종 점수 분포**를 조정하는 스탯 — 주사위 눈 자체를 조작하지 **않음**

**증가 방식:** 로그 스케일 계열. 행운이 높아도 실패 가능, 행운만으로 게임이 무너지지 않음, 높은 행운일수록 추가 효율 감소, 이론상 100% 안전 상태에는 도달 불가.

**UI:** 내부 계산 로직은 공개하지 않는다. 플레이어는 행운 수치·행운 관련 주사위·유물만 인지.

**미정:** 행운 수치 공식, “일부 확정” 주사위 선정 규칙, v0.1 리롤·칩 시스템과의 이행.

---

### 4.4 주사위 획득 및 교체

- **획득:** 상점에서 새 주사위 구매. 각 주사위는 서로 다른 숫자·특수면 구성.
- **교체:** 새 주사위 획득 시 기존 주사위를 교체 가능 — **육성 vs 갈아타기** 지속적 고민.

**기존 주사위 처리 (후보, 미정):**

| 방식 | 설명 |
|------|------|
| 판매 | 투자 비용 일부 환급 |
| 폐기 | 보상 없음 |
| 재활용 | 강화 재료 획득 |

---

### 4.5 주사위 성장

주사위는 획득만이 아니라 **지속 성장** 가능. 상점에서 **강화 키트** 구매 → 특정 주사위의 **특정 면**에 적용.

| 키트 | 효과 | 예 |
|------|------|-----|
| 숫자 증가 | 숫자면 +1 | 1→2, 5→6 |
| 숫자 감소 | 숫자면 −1 | 6→5, 3→2 |
| 진화 | 숫자면 → 특수면 | 5→H, 2→L |

**설계 의도:** 동일 종류 주사위도 성장 방향에 따라 전혀 다른 빌드 — 예: `1 2 3 4 5 H` vs `H H H H 5 6`.

**미정:** 강화 키트 종류 확장, 상점 경제·획득 빈도.

**예시 규칙 (가칭)**

|------|-----------|
| 짝수 점수 배수 | 짝수 관련 빌드 유리 |

※ 규칙 공개 시점(입장 전 전부 vs 일부)은 유물·진행에 따라 변동 가능.

## 9. 게임 플레이 (라운드·점수)

### 9.1 한 판 점수 공식

**목표 플로우 (§4.2):** 보드에 배치된 주사위만 굴림 → 효과 → 족보 → 점수.

**점수 공식 (유지):**

```
점수 = Σ(숫자) × Σ(족보 가치)
```

1. 배치된 주사위의 숫자 합 × 성립 족보 가치 합
2. 층·라운드 **최소 점수** 달성 시 진행 (로그라이크)

**v0.1 코드:** 10슬롯 일괄 굴림·칩 누적 — §4 보드·행운 이행 전 **과도기 구현**.

### 9.2 족보 철학 (확정)

- 포커처럼 **최고 족보 하나**가 아니라, **발견 가능한 모든 족보**를 동시에 획득한다.
- 족보끼리는 **순차 독립** 계산; 같은 족보 내 횟수만 **재료 소모**로 센다.
- **조합론(CnR)은 사용하지 않는다.**

계산 상세·족보 목록·가치: [design/systems/hand-scoring-v2.md](design/systems/hand-scoring-v2.md) (v1: [hand-scoring-v1.md](design/systems/hand-scoring-v1.md))

### 9.3 족보 가치 (밸런스)

- **v2 정본:** [hand-scoring-v2.md](design/systems/hand-scoring-v2.md) — 29종, 계열별 가치표.
- **현재 코드:** v2 규칙·가치표 (`hand_calculator.gd`).

### 9.4 라운드 클리어 조건

- **최소 점수 ≥ 목표** → 해당 라운드(또는 층 내 단계) 클리어
- 미달 시: 런 실패 또는 재시도 규칙 — **미정**

## 10. 경제 (칩·골드) — v0.1 과도기

> **방향:** §4.3 **행운**으로 운 제어 — **리롤 없음**. 아래 리롤·칩 소비 규칙은 v0.1 코드용이며 이행 후 폐기·개편 예정.

### 10.1 칩 = 라운드 점수 (v0.1)

- **칩**은 라운드 점수 (`§9` 공식)와 동일. 목표 칩 `T` 달성 시 해당 층 클리어.
- v0.1: 굴림 1회당 칩 1 소비 (`pachinko-chip-flow`) — v0.2 보드·행운과 **재설계 필요**.

### 10.2 골드 = 오버킬 보상·소비 재화

목표 칩 **달성 이후** 초과분(오버킬)에 따라 **골드**를 획득한다.

| 용도 | 설명 |
|------|------|
| 상점 | 주사위·강화 키트·유물·매수 (가격·오퍼는 추후) |
| ~~리롤~~ | **폐기 방향** — §4.3 행운으로 대체 |

**획득 공식 v2** (상세·예시: [design/systems/gold-economy.md](design/systems/gold-economy.md)):

- `T` = 목표 칩, `S` = 최종 칩, `r` = 2.0 (임계 배율)
- `S < T` → 0골드
- `S ≥ T` → `n = floor(log(S/T) / log(r)) + 1`, 획득 골드 = `n(n+1)/2`

예 (`T = 5`, `r = 2`): 5칩 → 1골드, 10칩 → 3골드, 20칩 → 6골드, 40칩 → 10골드.

층별 목표 칩 (v0.1): 10 → 20 → 40 → 80 → 160.

플레이 예 (v0.1): 목표 달성 후 추가 굴림 vs 상점 — v0.2에서는 **행운·배치·층 목표** 중심으로 재정의.

### 10.3 v0.1 코드 (리롤·골드 — 폐기 예정)
