# 고양이 주사위 로그라이크 — 프로토타입 기획

## 한 줄 컨셉

귀여운 고양이 주사위를 굴려 특수 효과 연쇄를 만들고, 매 판 미친 엔진을 완성하는 로그라이크.

**핵심 재미:** 주사위 선택 · 특수면 연쇄 · 효과 아이템 누적 · 스노우볼 · 도파민 폭발

## 핵심 구조 (2요소만)

| 요소 | 역할 |
|------|------|
| **주사위** | 상황/효과 생성 |
| **효과 아이템** | 상황에 보상/증폭 |

조커/카드 분리 없음 — **효과 아이템** 하나로 통합.

## 플레이 흐름

1. 주사위 선택 (최대 5)
2. 동시 굴림
3. 특수면 연쇄 발동
4. 효과 아이템 적용 (주사위 위 연출)
5. 돈 획득
6. 상점 (주사위 · 아이템 · 리롤)

## 시작

- 기본냥 ×3
- 10원

## 주사위

| 이름 | 면 | 효과 |
|------|-----|------|
| 기본냥 | 1~6 | 없음 |
| 황금냥 | … $ … | $ → +1 |
| 연쇄냥 | … ↺ … | 랜덤 1개 재굴림 |
| 복사냥 | … ★ … | 랜덤 효과 재발동 |
| 도박냥 | 0 0 0 8 8 8 | 꽝 / 8 |

## 특수면

| 기호 | 효과 |
|------|------|
| `$` | 즉시 돈 |
| `↺` | 재굴림 |
| `★` | 효과 재발동 |
| `!` | 다음 강화 (2차) |
| `+` | 숫자 +1 (2차) |
| `?` | 랜덤 (2차) |
| `0` | 실패 |
| `8` | 폭발 숫자 |

## 효과 아이템

| 이름 | 효과 |
|------|------|
| 통조림 창고 | $ 등장 시 +1 |
| 스크래쳐 | 재굴림 시 +2 |
| 캣타워 | 같은 숫자 2개↑ +3 |
| 생선 바구니 | 짝수마다 +1 |
| 과부하 쿠션 | 8 등장 시 +5 |

원칙: 짧은 텍스트 · 작은 효과 · 누적형 · 복잡 곱연산 지양
