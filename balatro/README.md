# Balatro 골격 데모

애니메이션·타로·행성·블라인드 특수 효과를 뺀 **포커 플레이 + 조커 150종** 최소 구현.

## 실행

ES 모듈 사용 — 로컬 서버 필요:

```bash
cd balatro
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 포함

- 표준 52장 덱
- 손패 8장, 플레이 최대 5장
- 핸드 4 / 버림 3
- 포커 족보 판정 (Four Fingers·Shortcut 패시브 지원)
- 칩 × 배율 × X배율 점수
- 조커 150종 정의 (Balatro v1.0.1o 기준)
- 앤티 클리어 → 상점에서 조커 구매

## 제외 (의도적)

- 카드/조커 에디션, 보스 블라인드, 타로·행성·스펙트럴
- 상점 리롤, 부스터 팩, 보상 태그
- 연출·사운드
