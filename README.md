# 주사위 고양이

주사위 연쇄 + **효과 아이템** 로그라이트 웹 프로토타입.

## 실행

```bash
python3 -m http.server 8765
```

http://localhost:8765/

## 플레이

1. 주사위 최대 **5개** 선택 (순서 = 슬롯 왼→오)
2. **굴리기!** → 특수면 연쇄 → **효과 아이템** (해당 주사위 위 말풍선)
3. **상점** — 주사위 / 아이템 / 진열 새로고침(2원)
4. **다음 라운드**

**시작:** 기본냥 ×3 · 10원

## 효과 아이템 (중복 구매 = 스택)

| 아이템 | 효과 |
|--------|------|
| 통조림 창고 | $ 칸마다 +1 |
| 스크래쳐 | 재굴림 칸마다 +2 |
| 생선 바구니 | 짝수 칸마다 +1 |
| 캣타워 | 같은 숫자 2개↑ +3 |
| 과부하 쿠션 | 8 칸마다 +5 |

조커 없음 — 주사위 + 효과 아이템만.
