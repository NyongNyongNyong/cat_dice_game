# Dice Ascent Prototype

One Deck Dungeon식 조우 카드와 주사위 할당 퍼즐을 참고한 독립 프로토타입.

## 실행

루트에서 정적 서버를 띄운 뒤 아래 경로로 접근한다.

```bash
python3 -m http.server 8765
```

http://localhost:8765/prototypes/one-deck-dice/

## 현재 루프

1. 층마다 조우 카드가 등장한다.
2. 역경 조우라면 두 선택지 중 하나를 고르고, 풀에서 주사위 2개를 고른다.
3. 적 조우라면 현재 주사위 풀 전체를 굴린다.
4. 나온 면의 속성/숫자를 보고 주사위를 잠그거나 리롤한다.
5. 조우 카드의 요구칸에 맞는 속성의 주사위를 할당한다.
6. 미해결 요구칸의 피해를 받고, 살아남으면 주사위 교체 또는 면 업그레이드 보상을 고른다.
7. 다음 층으로 올라간다.

## 조우 타입

- 적 조우: 현재는 기존처럼 카드 요구칸을 직접 해결한다. 상세 전투 구현은 보류.
- 역경 조우: 먼저 두 선택지 중 하나를 고르고, 풀에서 주사위 2개를 골라 단일 체크를 해결한다.

역경 조우의 윗 선택지는 하이리스크 하이리턴이다. 아래 선택지는 무난한 도전이다.

## 구현된 요구칸

- 공격/수비/민첩 속성 요구
- 특정 속성의 홀수 주사위 1개
- 특정 속성의 짝수 주사위 1개
- 특정 속성의 일정 수 이상 주사위 1개
- 특정 속성의 일정 수 이하 주사위 1개
- 특정 속성 주사위들의 합계
- 특정 속성 페어
- 특정 속성 3연속 스트레이트

## 주사위 면

주사위 면은 숫자 하나가 아니라 `속성 + 숫자`로 표현된다.

- 빨강 `공`: 공격
- 파랑 `수`: 수비
- 초록 `민`: 민첩

예를 들어 같은 `4`라도 `공4`는 공격 요구칸에, `수4`는 수비 요구칸에만 들어간다. 주사위 하나 안에는 공격/수비/민첩 면이 섞일 수 있다.

## 조작

- 풀 전체 굴리기: 현재 보유한 주사위 전부를 굴림
- 역경 선택지 클릭: 해결할 스킬 체크 경로 선택
- 역경 중 주사위 풀 카드 클릭: 이번 체크에 사용할 주사위 2개 선택
- 굴린 주사위 클릭: 할당 대상으로 선택
- 조우 요구칸 클릭: 선택한 주사위 할당
- 카드에 할당된 주사위 클릭: 회수
- 굴린 주사위 더블클릭: 잠금 토글
- 리롤: 잠기지 않고 할당되지 않은 주사위만 다시 굴림
- 랜덤 면 업그레이드 보상: 주사위 풀에서 주사위 하나를 클릭

## 보상

조우를 해결하면 보상 선택지가 나온다. 주사위 풀 크기는 기본적으로 늘어나지 않고, 기존 주사위를 교체하거나 개별 면을 강화한다.

- 주사위 교체: 보상 주사위를 고른 뒤, 기존 주사위 풀에서 하나를 선택해 교체한다.
- 랜덤 면 업그레이드: 보유 주사위 하나를 고르면, 해당 주사위의 랜덤 면 2개 숫자를 +1 한다. 현재 최대값은 8이다.

면 업그레이드는 개별 주사위에 적용된다. 예를 들어 `방패 #5`의 면들이 강화되어도 다른 방패 주사위에는 영향을 주지 않는다.
